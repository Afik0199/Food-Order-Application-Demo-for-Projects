# Food-Order-Application-Demo-for-Projects

A simple Java console-based Food Order Application built for learning and practice purposes.  
This project demonstrates the fundamentals of Object-Oriented Programming (OOP) using Java.

---

## Features

- User-friendly console interaction
- Food item selection system
- Order management
- Automatic receipt generation
- Simple and clean Java OOP structure

---

## Object-Oriented Programming Concepts Used

This project is designed to practice core Java OOP concepts such as:

- Classes and Objects
- Constructors
- Encapsulation
- Methods
- User Input Handling
- Basic Data Processing

---

## Project Structure

### 1. User
Handles user-related information and interactions.

### 2. FoodItem
Represents available food items including name, quantity, and price.

### 3. FoodOrderingApp
Main class of the application.  
Controls the overall execution flow of the program.

### 4. Receipt
Generates and displays the final order receipt.
